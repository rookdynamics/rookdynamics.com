Search like you'd talk to a partner

Type “domestic battery” and the actual charging statute comes up first — statute numbers work just as well. Criminal offenses and vehicle and procedure stay in separate sections so the charging statute never gets lost in the noise.

What's in the app
Zero network use

No accounts, no analytics, no telemetry. Nothing leaves the phone, ever.

Search-as-you-type

Suggested terms appear before you finish typing the word.

Recent searches

Sit on-device, one tap to run them again.

Partial statute numbers

Type what you remember and the results narrow from there.

Exact match, shown

Every result shows the citation, the matching subsection, and the line of text that got you there.

Full statute text

Subsection structure intact, a jump-to-subsection menu, and text you can select and copy.

Know what you're reading

Every results list carries a status badge showing offline mode, which corpus build is loaded, its date, and whether that build has been checked for currency. A stale build gets flagged on screen — not buried in a settings menu.
